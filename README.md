# 3D Web Structure Analyzer

ブラウザのみで動作する3D弾性骨組構造解析Webアプリケーション。

## セットアップ

```bash
npm install
```

## 起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## ビルド

```bash
npm run build
```

`dist/` に静的ファイルが生成される。任意のHTTPサーバーで配信可能。

## テスト

```bash
npm test
```

## 対応機能

### モデル構築
- 節点の作成・移動・削除（座標入力 / 作業平面上のクリック / ドラッグ）
- グリッドスナップ、XY/XZ/YZ作業平面、選択要素の配列コピー・ミラーコピー
- Undo / Redo（Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z）
- グリッドフレームジェネレータと4種類のテンプレート
- 節点・部材・節点荷重・部材荷重の表編集、TSVコピー＆ペースト
- 部材の作成・削除（2点指定）
- 支持条件の設定（自由 / 固定の切替）
- 材料特性の設定（名称・ヤング係数 E・せん断弾性係数 G・ポアソン比 v・熱膨張係数）
- 断面特性の設定（名称・断面積 A・ねじり定数 Ix・断面二次モーメント Iy, Iz・せん断面積比 ky, kz）
- 材料・断面ライブラリからのプリセット追加
- 部材端バネ（剛・ピン・回転バネ）の設定と静的縮約
- 両端ピン部材向けの一端捻り拘束（部材軸がグローバルX/Y/Z軸に平行な場合。実体は該当端節点の軸方向回転DOF固定のため、同じ節点を共有する他部材にも影響）
- 同一変位カップリング（master-slave DOF マッピング）
- 節点の6自由度ばね支持
- 2Dフレーム解析モード（X-Z / X-Y / Y-Z平面、面外DOFを自動拘束、全節点の面外座標0を検証）
- 2Dモードへ切り替える前に節点の面外座標を0へ明示変換する支援操作
- 部材コード角の設定
- 節点荷重（Fx, Fy, Fz, Mx, My, Mz）
- 部材荷重（集中・等分布・台形／部分分布・CMQ・温度・自重、ローカル／グローバル方向）
- 強制変位（支点沈下・支点回転。拘束した自由度に荷重ケース別に指定）
- 節点質量（固有値解析用の付加質量）
- 荷重ケースと荷重組合せ（ケース別荷重、係数付き組合せ解析）

### インポート / エクスポート
- FrameModelMaker-Web 形式（FrameJsonDocument）のインポート
- 脱落部材・未対応データ・境界条件・壁・名称補正を通知するインポートサマリ
- FrameModelMaker-Web 形式は3Dモデルとして読み込み（2DモードはProjectFile JSONで保存/復元）
- JSON形式のエクスポート / インポート
- サンプルモデル読込
- IndexedDBオートセーブ
- 旧スキーマの検証付きマイグレーション

### 解析
- 線形弾性・微小変形の3D弾性骨組解析
- 6自由度/節点（ux, uy, uz, rx, ry, rz）
- 12x12 Timoshenko梁要素剛性マトリクス（軸力・ねじり・2軸曲げ）
- せん断変形を考慮（Timoshenko梁理論）
- 3D座標変換（部材方向・コード角対応）
- 部材端バネの静的縮約（ピン・回転バネ）
- 同一変位カップリング（master-slave DOF、slave側拘束の master 伝播を含む）
- Web Workerによる非同期解析（UI非ブロック）
- request ID・中断・transferable配列に対応したWorkerプロトコル
- LDLt分解による連立方程式求解（分解再利用・複数RHS）
- 全荷重ケース／荷重組合せの一括解析と包絡結果
- 強制変位を含む分割解法（K_ff u_f = F_f − K_fc u_c、分解は1回のみ）
- 固有値解析（整合質量マトリクス＋節点質量、固有周期・固有振動数・刺激係数・有効質量比）
- 線形座屈解析（解析対象荷重の軸力による幾何剛性、座屈荷重係数 λ とモード形）
- 固有値・座屈解析用の部材自動分割（自動 / 1 / 2 / 4 / 8 分割）
- 特異剛性マトリクス発生時の不安定モデル診断（候補節点DOF、剛性ゼロDOF、両端ピン部材の表示）

### 結果表示
- Three.js による3D変形図（倍率調整・アニメーション表示可能）
- 部材内のたわみ曲線を反映した変形図（部材荷重・部材端ピン／バネを考慮した曲率積分）
- 固有モード・座屈モードの形状表示（結果表の行クリックで切替、アニメーション可）
- 断面力図（N, Vy, Vz, Mx, My, Mz、部材ごとの最大値ラベル表示）
- CMQ moy/moz の放物線バブル補正による断面力図反映
- 数値結果テーブル（節点変位・反力・部材端力・固有値・座屈）
- 入力表・結果表・固有値／座屈結果・ビューポート画像を含む解析レポート（Markdown / CSV / 印刷用PDF）
- WebGL表示とラベルを合成したPNG出力
- カップリング連成時の反力表示（代表行表示・重複防止）
- 荷重オーバーレイ（節点力・モーメント・集中荷重・等分布荷重・CMQ端部力/モーメント）
- 支持条件の可視化
- 荷重 / 支持の表示切替
- 節点番号・部材番号の表示切替
- ライト / ダークテーマ対応

## 符号規約

- **座標系**: 右手系（X, Y, Z）、Z上正
- **部材ローカル軸**: x = i端→j端方向、y/z = 参照ベクトルとコード角で決定
- **軸力**: 正 = 引張（軸力図 N も引張を正で表示）
- **荷重方向**: localX = i端→j端方向、localY/localZ = 部材ローカル軸に沿う
- **部材端力**: ローカル座標系で表示（Ni, Vyi, Vzi, Mxi, Myi, Mzi, Nj, ...）
- **断面力図**: 曲げモーメント図（My, Mz）は引張側に描画
- **強制変位**: 並進は長さ単位、回転は rad。グローバル座標系の正方向が正。同じ節点・自由度への複数指定は加算、同一変位カップリングで連成された支点同士は同じ値である必要があります

## 固有値解析・座屈解析について

- 質量は「材料密度 × 断面積」の整合質量と節点質量から作成します。力・長さ単位と整合する質量（力·s²/長さ、例: kN·cm 系なら kN·s²/cm）で入力すると、周期は秒、振動数は Hz になります。
- 刺激係数 β は、最大並進成分を 1 に正規化したモード形に対する値です。有効質量比は支点に寄与する質量も含めた全質量に対する比です。
- 座屈解析は、解析対象（荷重ケースまたは組合せ）の線形静的解析で得た軸力を基準状態とし、基準荷重の λ 倍で座屈することを表します。圧縮による正の λ のみを表示します。
- 1部材1要素では部材内の局所モードを表現できません（両端ピン柱のオイラー荷重で約 +21.6% の誤差）。部材分割数「自動」では、分割後の自由な自由度数が 1000 以下に収まる最も細かい分割（4 / 2 / 1）を選択し、分割できなかった場合は警告を表示します。
- 固有値問題は密行列ソルバー（Householder 三重対角化 + 陰的 QL 法）で解くため、分割後の自由度数は自由 1500 / 全体 3600 までです。
- 並進を伴わないモード（純ねじりなど）は、最大回転成分を 1 に正規化します。

## 制約事項

- 線形弾性・微小変形のみ対応
- 座屈解析は弾性曲げ座屈のみ（ねじり座屈・横座屈・局部座屈は対象外）
- CMQ 荷重を持つ部材の変形図は、荷重形状が不明なため節点変位の補間で描画
